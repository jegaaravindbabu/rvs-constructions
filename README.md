# RVS Constructions website

Premium multi-page website for **RVS Constructions**, Kodungaiyur, Chennai (est. 2013).
Static HTML, CSS and JavaScript (GSAP ScrollTrigger + Lenis). No build step.

## Pages
- `index.html` Home (cinematic video hero)
- `about.html`, `services.html`, `projects.html`, `contact.html`, `404.html`

## Run locally
Double-click `start-localhost.bat` (Windows), or run `python -m http.server 8000` and open http://localhost:8000.

## Deploy
Deployed on Vercel straight from this repository. Every push to `main` redeploys.
